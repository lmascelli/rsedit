* rsedit

/rsedit/ is a highly modular, headless text editor engine built in Rust. Inspired by the legendary architecture of GNU Emacs, /rsedit/ separates the text manipulation and layout logic entirely from the graphical frontend. Its behavior, keybindings, and layout are entirely programmable via an embedded, custom Lisp Virtual Machine.

** 🌟 Core Philosophy

1. *Total UI Decoupling:* The core (/rsedit_core/) does not know what a terminal or a pixel is. It calculates geometric bounding boxes and text slices, handing them to a "dumb" rendering client. You can swap the provided /crossterm/ TUI for a GUI framework (like /wgpu/ or /egui/) without rewriting any editing logic.
2. *Symbol Mapping:* Physical keystrokes do not trigger hardcoded Rust functions. Instead, a keystroke translates to a Lisp expression (e.g., /Ctrl+S/ -> /(save-buffer)/ or /a/ -> /(self-insert "a")/), which is evaluated dynamically by the Lisp VM.
3. *Everything is a Buffer:* From source code to the interactive Minibuffer, everything is backed by a highly optimized $O(1)$ /GapBuffer/.
4. *Dual-Layer Compositor:* The layout engine supports both a hierarchical Tiled Window tree and a Floating Popup layer natively.

** 🚀 Getting Started

*** Prerequisites
- Rust toolchain (Cargo)

*** Running the Editor
Clone the repository and run the TUI frontend. You can pass a file path to open it immediately:

#+begin_src shell
cargo run -- path/to/file.txt
#+end_src

** Basic Default Keybindings

    Typing: Standard alphanumeric keys self-insert.

    Movement: Arrow keys (Up, Down, Left, Right).

    I/O: Ctrl+S to save the current buffer.

    Exit: Ctrl+Q to quit.

** Vim mode

The optional =vim.lisp= module implements modal editing in Risp. The default
init loads it; run =M-x vim-mode= to enable it in the current buffer, or
=(vim-mode t)= from your configuration. An existing init needs
=(eval-file "vim")= after =commands=, =debug= and =common-keymaps=.

Normal, Insert, Replace and character/line/block Visual modes support counted
motions and operators, text objects, registers, keyboard macros, searches,
undo/redo, dot repetition and common Ex commands, including ranged regex
substitutions. The language's major mode and syntax hooks remain active.

See the =vim= manual page (=M-x rsedit-man=, then =vim=) for keybindings,
settings and the supported compatibility scope. =M-x vim-mode-disable=
restores the previous local keymap.

To enable Vim automatically in existing and future text/code buffers:

#+begin_src lisp
(global-vim-mode t)
#+end_src

Or enable it only for selected major modes:

#+begin_src lisp
(setq vim-mode-modes '(rust-mode risp-mode))
(vim-mode-refresh)
#+end_src

Service buffers and minibuffers are excluded by default. =vim-mode-predicate=
and =vim-mode-excluded-modes= customize automatic eligibility. Manual choices
in each buffer take precedence; =vim-mode-auto= returns to automatic policy.
The generic =buffer-created-hook=, =major-mode-hook=,
=after-change-major-mode-hook= and =find-file-hook= support other buffer
setup, and =set-major-mode= applies a new mode and its hooks.
