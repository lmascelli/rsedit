DESCRIPTION
    A buffer holds text, with its point, its mark, its undo history and its
    major mode. It may be visiting a file, and it may not: *scratch*,
    *Messages* and a directory listing are buffers with no file behind them.

    One buffer is current at a time, the one in the window you are typing
    in, and commands act on it without being told which. A buffer does not
    need a window: it goes on existing when nothing shows it.

SWITCHING
    C-x b asks for a buffer by name, and completes it: type any part of the
    name. C-x C-b lists every buffer, one per line:

          * notes.txt        fundamental-mode  /home/me/notes.txt
            *scratch*        fundamental-mode

    Three columns of marks, then the name, the mode and the file: the
    third is * for unsaved changes, and the first two are the marks below.
    In the listing, Return switches to the buffer on the line, g lists
    again, and q puts the listing away.

MARKING BUFFERS
        m               mark the buffer with >, for D and S
        d  k            flag it with D, to be killed by x
        s               flag it with S, to be saved by x
        u               take its marks off
        <backspace>     take the marks off the line above
        U               take every mark off
        x               save the S buffers, then kill the D ones
        D               kill the > buffers, or this one
        S               save the > buffers, or this one

    As in Emacs' Buffer Menu: m, d, s and u go on to the next line, the
    marks stay when the listing is drawn again, and

        D * notes.txt        fundamental-mode  /home/me/notes.txt
        >   *scratch*        fundamental-mode
         S  todo.org         fundamental-mode  /home/me/todo.org

    has notes.txt flagged to be killed, *scratch* marked, and todo.org
    flagged to be saved. s refuses a buffer that visits no file.

    Killing asks once, when some of the buffers have unsaved changes, with
    `yes-or-no': yes kills them all, and no keeps those and kills the
    others. The listing never kills itself.

KILLING A BUFFER
    C-x k asks which buffer to kill; Return with nothing typed kills the
    one you are in. A buffer with unsaved changes to a file asks first, and
    wants yes typed in full. A buffer with no file behind it is killed
    without a question. M-x kill-buffer-without-saving asks nothing.

    A window that showed the buffer shows the one you used before it, and
    a floating window showing it closes. Killing the last buffer leaves a
    new, empty *scratch*. A command still writing into the buffer, such as
    a shell command, is stopped.

READ ONLY
    A read-only buffer refuses every change to its text, from a key or from
    Lisp, undo and redo included, and saying so is all a key does there;
    point still moves. A listing is read-only, so what it shows can only
    change by being drawn again.

BUFFERS FROM LISP
    `buffer-create' makes a buffer without showing it, in a mode of its
    own if it is given one; a buffer that exists already is left as it is.
    `with-current-buffer' calls a function with a buffer current, without
    showing it, and makes the other one current again afterwards. It takes
    a function where Emacs takes a body:

        (with-current-buffer "notes.txt" (lambda () (buffer-string)))

    `buffer-put' and `buffer-get' keep values with a buffer, which go when
    the buffer goes. `set-major-mode' changes the mode, and the hooks that
    follow are in the `modes' page.

EXAMPLES
    Every buffer with unsaved changes:

        (let ((unsaved nil))
          (mapc (lambda (name)
                  (if (buffer-modified-p name)
                      (setq unsaved (cons name unsaved))))
                (all-buffer-names))
          unsaved)

    Write a report into a buffer of its own, and show it:

        (buffer-create "*report*")
        (with-current-buffer "*report*"
          (lambda () (clear-buffer) (insert "all done\n")))
        (switch-to-buffer "*report*")

    Make the current buffer read-only:

        (set-buffer-read-only t)

    The file a buffer is visiting, or nil:

        (buffer-file-name "notes.txt")
