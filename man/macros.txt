NAME
    macros - record what you pressed, and press it again

SYNOPSIS
    (kmacro-start-macro)
    (kmacro-end-macro)
    (kmacro-end-and-call-macro &optional COUNT)
    (kmacro-call-macro &optional COUNT)
    (kmacro-cancel-macro)
    (kmacro-recording-p)
    (kbd-macro-keys)
    (define-kbd-macro NAME KEYS)
    (kmacro-call-keys KEYS &optional COUNT)
    (kmacro-insert-counter &optional WIDTH)
    (kmacro-set-counter VALUE)
    (kmacro-counter)

DESCRIPTION
    Do the job once, with C-x ( before it and C-x ) after. Then C-x e does
    it again, as often as you like. Recording is not a rehearsal: the keys
    do their work while they are recorded, so a macro is what you get by
    doing the job once rather than by writing it down.

RECORDING AND PLAYING
        C-x (           start recording
        C-x )           stop recording
        C-x e           stop, if recording, and play the macro
        C-u N C-x e     play it N times

    C-x ) after nothing has been pressed keeps the macro you had. M-x
    kmacro-cancel-macro throws a recording away; what its keys did stays
    done, and undo takes it back.

WHAT IS RECORDED
    Keys, not commands. A command that reads a character, such as M-z,
    plays back with the character that was pressed; C-u and its digits
    play back too; and a key bound to something else since then plays
    back as what it does now.

    A paste is not recorded. The terminal sends it as text rather than as
    keys, so a macro recorded over a paste plays back without it.

KEEPING ONE
    C-x e plays the last macro recorded, and there is only one. To keep a
    macro, give it a name:

        (define-kbd-macro 'tidy-line "C-a C-k C-y")

    That makes an ordinary command: M-x finds it, C-h f describes it, and
    a key can be bound to it. (kbd-macro-keys) gives the last macro in the
    same notation, so keeping one is copying that line into init.lisp.

    To play a macro inside another, play a named one. A key bound to
    kmacro-call-macro plays whatever the last macro is at that moment,
    which while recording is the one being recorded.

THE COUNTER
    C-x C-k C-i inserts a number, and the number goes up by one each time
    it is inserted. Starting a recording sets it to zero, and C-x C-k C-c
    to any other number. So

        C-x (  C-x C-k C-i  C-n C-a  C-x )      then  C-u 9 C-x e

    numbers ten lines, from 0 to 9. (kmacro-insert-counter 3) pads the
    number with zeros to three digits, 007, so that numbered lines sort in
    the order they read. A macro that inserts the counter twice inserts
    two different numbers.

UNDO
    Each time a macro is played is one undo step: a macro played twenty
    times can be taken back one playing at a time.

WHEN IT STOPS
    At the first command in it that fails. The rest of the macro and the
    playings left are abandoned, and the echo area says so: every key
    after a failure would be pressed in a state the recording never saw.

    Nothing else stops one, C-g included: a macro plays to its end or to a
    failure. A macro that plays itself stops sixteen levels deep, with
    "Keyboard macro is nested too deeply".

EXAMPLES
    Keep a macro, on a key of its own:

        (define-kbd-macro 'tidy-line "C-a C-k C-y")
        (define-key nil "C-c m" 'tidy-line)

    The last macro, written the way define-kbd-macro takes it:

        (kbd-macro-keys)

    Press keys from Lisp, three times over:

        (kmacro-call-keys "C-e C-n" 3)

    Start the counter at 1, for a numbered list:

        (kmacro-set-counter 1)

KEYS
    C-x (                   kmacro-start-macro
    C-x )                   kmacro-end-macro
    C-x e                   kmacro-end-and-call-macro
    C-x C-k C-i             kmacro-insert-counter
    C-x C-k C-c             kmacro-set-counter
