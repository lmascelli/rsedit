NAME
    rectangles - blocks of text, cut by column

SYNOPSIS
    (rectangle-mark-mode)
    (kill-rectangle)
    (copy-rectangle-as-kill)
    (delete-rectangle)
    (yank-rectangle)
    (open-rectangle)
    (clear-rectangle)
    (string-rectangle STRING)
    (rectangle-bounds)
    (killed-rectangle)

DESCRIPTION
    The region between point and the mark is a run of text: from the
    middle of one line, through whole lines, to the middle of a later one.
    A rectangle is the other thing the same two positions describe: the
    block of columns between them, on every line from one to the other.

    The rectangle commands work from point and the mark whether or not the
    block is shown. C-x <space> shows it: the region is drawn as the block,
    so you see what you are about to cut. With no mark set, C-x <space>
    sets one where point is. Any edit ends it, as any edit ends a region.

THE COMMANDS
        C-x <space>     show the region as a block, or stop
        C-x r k         kill the block, keeping it for C-x r y
        C-x r M-w       copy the block, killing nothing
        C-x r d         delete the block, keeping nothing
        C-x r y         put the kept block back, its corner at point
        C-x r o         open a block of spaces, pushing the text right
        C-x r c         blank the block out with spaces
        C-x r t         replace the block with a string on every line

    C-x r c leaves what was to the right of the block in its column, which
    a table whose columns must line up wants; C-x r d closes the gap. The
    string C-x r t asks for need not be as wide as the block, and the text
    to its right moves to suit. While you type it, it is shown on every
    line of the block, and nothing changes until you press Return.

SHORT LINES
    A line that stops before the left edge of the block is still one of
    its lines. Kill, copy and delete take what is there and leave the
    line alone, so it gives the block an empty line. Open, yank and C-x r
    t first fill the line out with spaces to the edge. C-x r c leaves a
    short line alone, since there is nothing on it to blank.

A BLOCK OF NO WIDTH
    With its two corners in the same column, the block is a position on
    every line. Nothing is cut, replaced or opened, but C-x r t still
    inserts its string there. This is how to put a prefix in front of a
    run of lines: C-x <space>, C-n down the lines, then C-x r t and the
    prefix.

WHERE THE BLOCK IS KEPT
    A block killed or copied is kept on its own, not on the kill ring: C-y
    still yanks the last ordinary kill, and C-x r y the block, in the shape
    it was cut. One block is kept, and the next kill or copy replaces it.

    C-x r y puts each line of the block in at point's column, on the line
    point is on and the ones below, pushing what is there to the right. A
    block yanked near the end of the buffer adds the lines it needs.

WHERE POINT ENDS UP
    At the top-left corner of the block, after each command that changes
    the buffer: where the block begins, and where the next thing done to
    it starts from. C-x r y leaves point where it was, which is that
    corner. C-x r M-w changes nothing, so the mark stays and the block
    stays selected.

LIMITS
    Columns count characters: a tab is one column, and so is a character
    the terminal draws two cells wide. The terminal draws a tab wider than
    that, so on a line with tabs the block cut is not the block shown.

EXAMPLES
    Prefix the lines from the mark to point with "> ", the two in the same
    column:

        (string-rectangle "> ")

    The block between point and the mark, as numbers:

        (rectangle-bounds)      ; (TOP-LINE BOTTOM-LINE LEFT RIGHT)

    The lines of the block last killed or copied:

        (killed-rectangle)

    Copy the first three columns of lines 1 to 4:

        (progn (goto-line 1) (set-mark)
               (goto-line 4) (forward-char 3)
               (copy-rectangle-as-kill))

KEYS
    C-x <space>             rectangle-mark-mode
    C-x r k                 kill-rectangle
    C-x r M-w               copy-rectangle-as-kill
    C-x r d                 delete-rectangle
    C-x r y                 yank-rectangle
    C-x r o                 open-rectangle
    C-x r c                 clear-rectangle
    C-x r t                 string-rectangle
