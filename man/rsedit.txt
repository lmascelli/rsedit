NAME
    rsedit - an editor with an embedded Lisp

DESCRIPTION
    rsedit is a text editor whose behaviour is written in its own Lisp. The
    Rust underneath provides mechanisms that cannot sensibly be swapped --
    the buffer, the display, the evaluator -- and policy lives in `.lisp`
    modules that can be read, edited and reloaded.

    A feature that can be written as a module is one, which is why dired,
    the completion strip, electric-pair and this manual reader are all
    Lisp.

MODULES
    Loaded by your init.lisp with `require', each after the modules it
    needs. Comment one out and the editor comes up without it, missing
    exactly that feature, unless a module still loaded needs it. Plugins,
    modules written by others, are loaded the same way: see `plugins'.

    commands             defcommand, and the command registry's Lisp side
    debug                message, and the *Messages* buffer
    common-keymaps       the default bindings
    indent               what Tab does; a mode plugs its own rule in
    minibuffer           M-:, an expression evaluated at a prompt
    rust-mode            colouring for Rust
    risp-mode            colouring and indentation for rsedit's own Lisp
    cc-mode              colouring and indentation for C and C++
    python-mode          colouring and indentation for Python
    toml-mode            colouring and indentation for TOML
    bash-mode            colouring and indentation for Bash
    dired                a directory in a buffer, and C-x C-r
    completion           the strip that narrows as you type
    preview              C-x r t shows its replacement before you commit
    clipboard            kills also reach the system clipboard
    electric-pair        closing delimiters that type themselves
    buffer-list          C-x b, and C-x C-b
    shell                M-! and its output buffer
    manpage              this
    help                 C-h f, C-h k, C-h b -- the editor describing itself
    occur                M-s o, M-s g, and the lists M-g n walks
    compile              C-c c, and jumping to what it complained about
    theme                C-c t, and how faces are drawn
    vim                  modal editing, off until M-x vim-mode
    completion-at-point  where completions come from

FINDING YOUR WAY
    C-h f names a function, C-h v a variable, C-h k a key -- press it and be
    told what it would have done. C-h b lists every binding in effect, C-h a
    searches every name there is, and C-h ? lists the help keys themselves.

    Half-way through a prefix, the help key says where the prefix goes: C-x
    C-h lists everything C-x leads to.

    All of it is answered by the editor rather than by a table written down
    beside it, so a page is right about the buffer you are in -- the mode's
    binding where a mode has one, and the transient map's while a question
    is being asked.

    The prefix is the variable `help-key'. On a terminal that still sends
    Backspace as C-h, (setq help-key "C-c h") and (install-help-keys) move
    the whole tree.

IN A WINDOW
    rsedit runs in the terminal it is started from. With --gui, or when its
    standard input is not a terminal, it opens a window of its own instead,
    drawn with the monospace font file --font names, or a built-in one.

    The window is the same editor: keys go through the same keymaps, and the
    toolbar's Open, Save, Save as, Copy, Cut, Undo and Vim run their
    commands as M-x would; they are greyed out while a prompt is open. Its
    - and + buttons make the text smaller and larger, and a file dropped on
    the window is opened.

    On Linux and Windows, Ctrl+Shift+C, Ctrl+Shift+X and Ctrl+Shift+V copy,
    cut and paste; Ctrl+C, Ctrl+X and Ctrl+V keep their bindings, so C-x
    and C-v still work. On macOS, Cmd+C, Cmd+X and Cmd+V copy, cut and paste,
    and Cmd+O, Cmd+S, Cmd+Shift+S, Cmd+Q, Cmd+Z and Cmd+Shift+Z open, save,
    save as, quit, undo and redo. Home, End, Delete, Page Up and Page Down
    move as they do in other programs, and as vim has them in its normal
    state; they cannot be bound.
