NAME
    virtual-text - text shown in a window and not in the buffer

SYNOPSIS
    (make-virtual-text POSITION TEXT &optional FACE PRIORITY CATEGORY)
    (clear-virtual-text &optional CATEGORY)
    (delete-virtual-text HANDLE)
    (virtual-text-at POSITION)

DESCRIPTION
    Text the reader should see at a place in the buffer without its being
    in the buffer: a hint from a language server, the name of a parameter,
    what a command is about to insert. C-x r t shows its string this way,
    on every line of the rectangle, while you type it.

        (make-virtual-text (point) ": int")

    draws ": int" in front of the character at point, pushing the rest of
    the line to the right, and returns a handle: a number that names it.
    The buffer does not change. Nothing is marked modified, there is
    nothing to undo, and saving writes the file without it. FACE is comment
    unless it is given, so that it does not pass for the text around it.
    An empty TEXT makes nothing and returns nil, and a POSITION past the
    end of the buffer is its end.

WHERE IT GOES
    In front of the character at POSITION. For the end of a line, give the
    position of its newline -- (end-of-line) and then (point) -- and for the
    end of the buffer (point-max). Several at one position are drawn in
    order of PRIORITY, highest first, and of two with the same, the older
    first.

    The cursor is never inside it. With point at its position the cursor is
    drawn after it, on the character it is in front of; C-f and C-b step
    over it in one go, and a click on it puts point on that character.

AS THE TEXT CHANGES
    Typing before it carries it along, and so does typing at its position:
    it stays in front of the character it was in front of. Deleting the
    text around it leaves it where the deletion began. No edit removes it,
    not even one that takes away everything around it; reverting the
    buffer removes all of it.

CATEGORIES
    CATEGORY names whoever made the text, and is virtual-text when it is not
    given. It is what lets a maker replace its own in one call, and then
    place the new, without keeping their handles and without disturbing
    anyone else's -- what a language server does after every edit:

        (clear-virtual-text 'my-hints)

    With no category `clear-virtual-text' clears all of it, and it says how
    many went. `delete-virtual-text' takes away one, by its handle.
    `virtual-text-at' lists what is shown at a position, each as (TEXT FACE
    CATEGORY HANDLE), in the order it is drawn.

EXAMPLES
    A note at the end of the line point is on:

        (end-of-line)
        (make-virtual-text (point) "  <- look here" nil 0 'my-notes)

    What is shown at point:

        (virtual-text-at (point))

    Take the notes away:

        (clear-virtual-text 'my-notes)
